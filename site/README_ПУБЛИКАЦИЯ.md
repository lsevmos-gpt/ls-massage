### Добавление специалиста в новый клуб
1. Сначала добавить подтверждённого специалиста в `content.json` с `club_id=olympia` и в `clubs[olympia].specialist_slugs`.
2. Подготовить отдельный портрет без искажения, страницу `/specialists/<slug>/`, тарифы и контакт — только по полученным данным.
3. Разместить карточку в соответствующем разделе и на `/clubs/1-konnoi-armii-25a/`; не менять прайсы существующего клуба.
4. Сверить все ссылки/адреса/мобильную версию. Индексация пока выключена (`noindex,nofollow`).

Текущая публикация на REG.RU не подтверждена. Пуш в `lsgptai-svg/ls-massage/main` сохраняет исходники и сам по себе не выполняет FTPS-деплой.

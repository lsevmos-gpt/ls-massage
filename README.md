## Публикация

Файл `.github/workflows/deploy-site-manual.yml` называется **Deploy massage to REG.RU (manual, guarded)**.

- При обычном push файлов `site/**` автоматически запускается только проверка `plan` (без записи на сервер).
- Разовая публикация 17.10.2026 была запущена явно подтверждённым коммитом маркера `.github/trigger-massage-publish.txt` с сообщением `[publish-massage]`; это не обычная автопубликация всех изменений.
- Для публикации открыть **Actions → Deploy massage to REG.RU (manual, guarded) → Run workflow**.
- Выбрать `mode: deploy` и ввести в `confirm_domain` значение `massage.liniyasporta.ru`.
- Процесс проверит комплект v11 и FTP-корень, сделает резервную копию публичных файлов в Actions artifact на 7 дней, загрузит файлы **без удаления серверных файлов** и проверит шесть страниц по HTTPS.
- Если нужен только повторный предварительный просмотр, выбрать `mode: plan`.

В логах `plan` слова `Removing old file` отображаются при `--dry-run` как предполагаемые операции. При таком запуске реальные серверные файлы не удаляются и не перезаписываются.
